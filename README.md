# 🩸 Vorosha App

Vorosha App is a **blood donation platform** designed to bridge the gap between **donors** and **receivers**.  
The app allows users to **log in as a donor or receiver**, **send donation requests**, and **respond to incoming requests** — making blood donation simple, fast, and accessible.

---

## 🚀 Features

- **User Authentication**  
  - Separate login for **Donors** and **Receivers**  
  - Secure registration and login system  

- **Donation Requests**  
  - Receivers can send blood donation requests  
  - Donors receive notifications and can accept or reject requests

- **Request Management**  
  - View all sent and received requests  
  - Track request status in real time

- **Clean & Simple UI**  
  - Easy to navigate for all users  

---

## 🛠️ Tech Stack

- **Frontend:** HTML,CSS,Bootstrap
- **Backend:** Django, Python  
- **Database:** SQLite
